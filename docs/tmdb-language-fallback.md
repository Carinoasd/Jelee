# TMDB 使用者語言與簡介回退

正式管理員的電影／劇集搜尋及電影／劇集／季／集詳細查詢，省略 `language` 時使用已認證使用者的四語偏好；未設定或未知偏好採 `zh-CN`。明確查詢參數優先，空值與未知語言仍回400。客戶端的 `Accept-Language` 不覆蓋身份中的偏好。OpenAPI同步說明這項預設。

## 回退與來源

詳細查詢在簡介缺失或只有空白時，沿 `zh-CN → zh-TW → ja-JP → en-US` 從偏好位置往後查詢。例如日文只嘗試日文及英文。僅填補缺失簡介，保留第一個回應的標題、日期、身份、語言與取得時間。`overviewSource.requestedLanguage` 及 `fetchedAt` 記錄提供該段簡介的請求語言及原始取得時間；這不是文字語言偵測。所有語言都缺失時輸出空簡介與空來源／零時間。

季與單集回退核對provider身份及系列／季／集號碼；季回退只填現有且身份相符的單集，不加入新單集。每段季／集簡介可有不同來源。應用層複製季的單集陣列，避免合併改動供應商快取。

搜尋僅在候選頁為空時回退，第一個非空頁即停止，不跨語言合併或自動選定。回應查詢語言仍是使用者要求，候選語言及簡介來源則是實際請求語言；每個候選仍須人工確認。

整段回退共用15秒期限、既有受控出站／限流／冷卻／重試與語言分區快取。供應商錯誤、404、取消或逾時立即結束，不以另一語言掩蓋錯誤。合併結果不寫回原始快取，不寫媒體庫、NFO或圖片。

## 驗證與尚缺範圍

應用測試覆蓋回退顺序、共用期限、保留原欄位、空白／全缺、來源時間、提前停止、錯誤／取消、身份不符及季陣列隔離。六個正式HTTP路由驗證可信偏好、明確覆蓋、缺失／未知偏好、空參數拒絕與客戶端標頭不能覆蓋。

正式TMDB適配器經實際TLS與應用服務，驗證四語詳細回退、兩次查詢只各取一次原始語言資料、原始快取不被合併污染、搜尋空頁回退與待確認契約。刻意把詳細回退限制為首個語言，實際TLS驗收失敗；逐位元恢復後相關完整回歸通過。執行統計及來源hash見[證據](evidence/tmdb-language-fallback.json)。

G14.5仍只部分完成：媒體庫語言設定與選擇優先序、圖片語言偏好、其他文字欄位回退、完整前端與原100電影／20劇集驗收尚缺。供應商本身可能回傳原文標題，本階段沒有假稱標題已翻譯。全案仍在第3階段。
