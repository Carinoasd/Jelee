## 迁移和品牌范围

采用需求已允许的渐进替换。保留原 C# 源码作历史比对与回滚，新增 Go 入口不反向代理到旧服务。G02/G05 等功能裁剪可先在 Go 的可达 API 面成立，但旧源码实体、表、翻译、图标未清理前，各完整子项不能标为完成。

根许可证、贡献名单与必要第三方 NOTICE 不改写。审计、原始需求、迁移说明里的旧品牌名称属于可解释来源引用。品牌扫描可以为这些**明确文件/原因**设法律与需求来源例外，不能把整个旧源码树列为品牌通过白名单。若保留旧树，完整仓库扫描仍应显示实际未完成结果；新 Go 范围通过不能冒充全仓通过。
