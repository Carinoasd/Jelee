# NFO 單值欄位的別名衝突

唯讀確認套用要求單值欄位沒有歧義。同一個目的欄位的不同 XML 標籤會共用重複計數：

| 目的欄位 | 標籤 |
| --- | --- |
| 標題 | title、name、localtitle、seasonname |
| 日期 | premiered、releasedate |

名稱依既有 XML 解析規則忽略大小寫。以上任一組出現兩個直接子標籤時，正式欄位投影會拒絕，即使值相同或其中一個是空值。原始值與原始 NFO 保持，不會默默選取最後一個值。originaltitle、plot、lockdata、lockedfields 的既有單值檢查保持。

單一合法別名仍可套用；actor 等巢狀節點內的 name 不計入項目標題。通用文件解析與原文複製的相容行為保持，本次修正作用於正式確認套用的嚴格投影。

歧義的有效 XML 屬於無法安全套用的內容，NFO-only 與 NFO／TMDB 入口回503。它不會成為解析損壞或缺失回退，不查詢供應商，也不保存欄位、鎖、確認觀察、分類、版本或稽核。

資料庫仍使用 schema26，001–026保持不變。此處修正既有單值歧義檢查，不新增投影版本或改變資料格式。其他NFO欄位、季集／多項目來源與完整匯入、前端及無損回寫仍未完成；參見[目前鎖定契約](nfo-lock-only.md)。
