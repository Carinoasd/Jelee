# G05 指南核心裁剪

刪除已解除註冊的指南實作與介面，共834行。唯一保留來源的編譯相依是圖片快取天數，已改為該來源的本地常數，維持兩天；沒有建立替代指南服務。

整合驗收檢查兩個程序集均不含指南型別，其餘退休服務仍不可解析，媒體庫目前所需的頻道、錄製、節目來源與調諧器服務可正常解析。原有內容摘要編碼的測試斷言保留，只更新提到已移除指南的註解。

指南排程及其觸發來源已於先前階段刪除。本階段不修改既有遷移、存量節目／錄製資料或原媒體。直播、錄製、頻道與調諧器其他核心仍待裁剪，G05仍部分完成。完整回歸與反向驗收詳見[證據](evidence/guide-core-removal.json)。
