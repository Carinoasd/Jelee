# 一般 DTO 移除直播與錄製增補相依

依 G05，一般DTO移除錄製管理器與lazy直播管理器的建構相依，刪除單筆／批次直播節目與Channel增補，以及活躍錄製的型別／名稱覆寫。沒有空服務替代；一般媒體、圖片繼承、計數與使用者資料的既有程式保留。

既有兩份測試只調整建構mock參數，斷言保留；14項DTO回歸全部通過。完整Debug17套件4,808 Passed、21 NotExecuted、零失敗；格式檢查通過，有工作區載入警告。既有實體仍相依錄製狀態，測試保留該實體所需mock，未宣稱DTO全部下游都不查錄製服務。

原提議一次刪除七個核心實作／介面並改DTO、視圖及DI，被自動核准審查拒絕，原因是尚未先分批解耦、影響廣泛。原操作沒有執行；改先做DTO單層解耦，後續工具審查已允許執行。七個核心檔案及視圖／DI／程序集載入仍逐位元符合基底，下一步先解耦使用者視圖，再評估核心刪除。

G05仍部分完成；核心服務、設定與資料、實體及媒體庫相依及真客戶端／LAN驗收仍待完成。公開建構式改動形成實際ABI差異，保持門禁。
