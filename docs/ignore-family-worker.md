# 合併忽略模式的工作程序整合

正式 runner 已接入合併忽略模式；公開提交與服務啟動設定仍待接入。

## 任務執行

`FamilyIgnoreOptions` 要求完整的儲存與原生掃描依賴。啟動時確認 repository 支援模式辨識與既有忽略流程，避免錯誤設定落入普通掃描。認領使用獨立 `FamilyIgnore` 能力及精確的模式／大小寫／程式版本／證據版本合同；只有原模式能力的 worker 無法認領合併模式，反向也一樣。

新任務可在尚未保存來源時讀取初始進度。任一已存在的來源失效或世代不一致都拒絕讀取；分類開始後必須兩份來源清單齊全，並保持基線版本一致。這修正了原生驗收發現的新任務啟動問題。

執行順序為原生掃描、整頁原子基線分類、NFO／probe、自有規則來源復核、舊格式來源復核、基線缺失邊界復核、共同封存及發布。每路分頁保留自己的 token，受頁數上限與取消控制；資料庫錯誤、來源改變、callback 失敗或未完成列舉都中止。三路全完成才封存。成功終態使用 family 發布入口，失敗與取消沿用原任務流程。

只有已完成分類、清單世代及基線版本相符且兩份来源有效，NFO／probe 才能處理保留下來的清單。被排除的 NFO 不送入解析器。來源不可用時保存未知分類，保留舊基線並要求確認；來源改變時任務失敗，不發布基線。
