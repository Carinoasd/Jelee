# NFO 數值單值歧義

確認套用時，`year`、`runtime`、`rating`、`userrating` 各自只能出現一次。`communityrating` 與 `rating` 共用同一個目的欄位，因此兩者同時出現也拒絕。名稱不分大小寫；相同值的重複元素仍有歧義。

檢查只計算項目根元素的直接子元素，巢狀 `ratings/rating` 的多來源評分保持可讀。通用文件解析器保留既有相容行為與原始 XML；確認套用則在供應商查詢與保存前回覆 503。有效 XML 的單值歧義不被當成損壞 NFO 的回退條件。

本段補上確認投影的守衛。數值目前仍由通用解析器提取，尚未接入項目的有型別保存、人工編輯或 API 回應；九文字投影版本、資料庫第 28 版與所有已發布遷移保持。G39.3 與 G39.6 仍為部分完成。

驗證涵蓋公開 Reader 與實際 HTTP／TLS／NFO／PostgreSQL。年份衝突先重現錯誤接受 200，修正後拒絕；片長、評分別名和使用者評分也各自有先失敗再通過的回歸。停用正式年份守衛時，完整流程再次失敗，復原後重跑。數值邊界、逗號小數、片長單位及巢狀多來源評分保持可讀。實測結果與來源雜湊見[證據](evidence/nfo-numeric-ambiguity.json)。

實測：Windows 29 套件／3252 通過事件（含父測試）／474 測試略過，略過身份與前版相同；Linux 五套件 race 1118 通過事件，零失敗零略過。完整 HTTP／TLS／NFO／PG 73.765 秒，零失敗零略過，包含 NFO-only 與融合拒絕、零保存／稽核及原 120 筆合成確認寫入。vet／產品 build／增量品牌／gitignore 通過；全量品牌仍 14735 違規。56 份已發布遷移、原授權／需求與五待授權核心保持。
