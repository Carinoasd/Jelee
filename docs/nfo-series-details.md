# 劇集計數、狀態與播出資訊

schema37 本地驗收已完成，遠端CI以本次推送結果為準。

## 保存內容

`tvshow` 新增五個有型別的 facts：

| NFO 元素 | 保存欄位 | 範圍與行為 |
| --- | --- | --- |
| `season`／`seasonnumber` | `seasonCount` | 整數 -1–1000000 |
| `episode` | `episodeCount` | 整數 -1–1000000 |
| `status` | `seriesStatus` | 非空白文字，最多 128 UTF-8 位元組 |
| `airs_dayofweek` | `airsDayOfWeek` | 非空白文字，最多 128 UTF-8 位元組 |
| `airs_time` | `airsTime` | 非空白文字，最多 128 UTF-8 位元組 |

原有 `SeriesNfoSaver.cs` 會把未知季數及集數寫成 `-1`。這個值與零、未指定值保持區別；只有 `tvshow` 的計數接受 `-1`，季與單集的編號仍不接受負數。

播出星期與時間保留原文字，例如 `Friday` 或 `9 PM`，不推斷時區或建立排程。這些欄位是描述資料，不會因保存而啟動背景工作。

## 優先順序與鎖

人工 `null` 是明確清除，後續 NFO 確認保留人工值。只修改手動鎖開關不會丟棄 NFO 值來源；給定新的人工值會解除該值原本的 NFO 來源與獨立鎖證明。

新劇集投影 `series-details-v1` 包含 33 欄：九個文字欄位與 24 個 facts。新讀取劇集全域鎖涵蓋全部 33 欄；電影仍使用 28 欄投影。歷史已保存投影保持原語義。

`SeasonCount`／`Season`、`EpisodeCount`／`Episode`、`Status`／`SeriesStatus`、`AirDays`／`airs_dayofweek`、`AirTime`／`airs_time` 等別名對應各欄位鎖。沒有值時只保存獨立鎖，不建立假的值來源或更新時間。

## 驗證與限制

寫入前拒絕重複元素、季數別名衝突、超界計數及超量文字。讀取觀察擁有自己的計數指標，呼叫端修改不能影響重核。

新遷移只新增 schema37；001–036 的 72 份已發布 SQL 保持。保留新欄位、鎖或新投影來源時拒絕降版，避免丟失資料。

季與單集的實際來源綁定、匯入、前端和無損回寫仍待接續；本批不代表第三階段完成。
