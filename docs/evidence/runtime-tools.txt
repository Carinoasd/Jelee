Follow-up download hardening after independent review:
HTTPResponse.read(n) could previously wait indefinitely for n bytes under a slow trickle, preventing the outer elapsed-time check. Replaced body reads with read1 and added a raw socket reader that checks the shared absolute deadline before every receive and updates the socket timeout to the remaining time. This also covers HTTP status/header parsing and retains the same deadline across HTTPS redirects. No manifest pin or installed byte changed.
