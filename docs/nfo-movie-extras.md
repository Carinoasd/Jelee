# 電影 NFO 日期、預告片與圖片參照

schema36 的本地驗收已完成；遠端 CI 以本次推送結果為準。

## 保存行為

- `dateAdded` 保留原本日期表示，接受有效的 `YYYY-MM-DD`、`YYYY-MM-DD HH:mm:ss` 或 RFC3339（最多九位小數秒），不替無時區日期指定時區。
- `trailers` 保存有序參照字串，每筆最多 4096 UTF-8 位元組、128 筆，合計最多 16384 位元組。
- `art` 保存有序的 `kind`、`location`、可選 `preview` 與 `season`。缺少季數與季數零保持區別；季數範圍為 0–1000000。
- 圖片最多 128 筆；種類最多 64 位元組，位置及預覽各最多 4096 位元組，全部圖片文字合計最多 16384 位元組。
- 確認資料只保存參照，不因參照而下載圖片、讀取預告片或改寫原始 NFO。

人工 `null` 清除整個欄位；預告片與圖片也接受空陣列清除。人工值優先於再次確認的 NFO。值、來源、獨立欄位鎖與確認觀察沿用同一交易。

## 欄位鎖與來源

新讀取的 `lockdata=true` 保護目前全部 28 個已支援欄位（九個文字欄位與 19 個 facts）。沒有值的欄位只建立獨立鎖定來源，不產生值來源或更新時間。歷史已保存的投影版本保留原語義。

`DateAdded`／`DateCreated` 對應日期；`Trailer`／`Trailers`／`RemoteTrailers` 對應預告片；`Art`／`Artwork`／`Images` 及圖片種類別名鎖住整組圖片參照。

## 輸入檢查

寫入投影拒絕重複日期、重複圖片屬性（不分大小寫）、衝突的 `aspect`／`type`、非法季數及超量資料，不回傳部分投影。巢狀 `fanart/thumb` 與 `art` 圖片保留季數。觀察物件擁有自己的切片及季數指標，呼叫端修改不能污染後續重核。

API 增加三種 facts 變體，合計 11 種變體、19 個 facts；套用報告上限為 28。圖片 `season: null` 表示未指定；其他型別的未知欄位仍拒絕。
