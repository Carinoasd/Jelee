# G03 HTTP 訊息鍵靜態驗收

Go HTTP 翻譯合同原本只掃描三個固定來源，以正規表示式抽取部分錯誤碼。現在解析該目錄所有正式 Go 檔案的語法樹，排除測試檔，支援錯誤碼的字串／原始字串與狀態常數。對照英文資源鍵後，缺少翻譯或沒有正式來源引用的鍵都會使測試失敗，並確認四語可翻譯每個被引用的鍵。

動態錯誤碼、函式參數、無法靜態抽取的賦值／宣告、呼叫簽名變化或語法錯誤會明確失敗，要求更新驗收。八個隔離情境覆蓋新檔、狀態常數、原始字串、測試檔排除及動態／錯誤來源；另驗證缺失與未使用鍵同時被抓出。

這是來源靜態引用門禁，不證明每個分支在執行時可達。範圍只有 Go HTTP 錯誤訊息；舊伺服器 UI 未使用鍵、前端元件硬編碼與文字格式驗收仍待完成，G03保持部分完成。現有 CI 的 HTTP 測試會執行此門禁，未放寬任何檢查。

本階段沒有套用仍待使用者授權的直播五檔刪除，也沒有改變產品行為或資源內容。[驗證證據](evidence/http-i18n-key-audit.json)。
