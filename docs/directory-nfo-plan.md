# 影集與季的資料夾來源

前置版本：單集 NFO `3d5eb4e6dd`，影片種類匯入 `e010c6a548`。本段已完成本地驗收；範圍及限制見[契約](directory-nfo-sources.md)。

## 交付範圍

1. 用獨立資料表保存 Series／Season 的真實資料夾位置，不在 `media_sources` 建立虛構影片。
2. 保存同媒體庫的父子關聯：Season 的父層為 Series，Episode 可指定 Series 或 Season。資料庫拒絕跨庫及不合法種類組合。
3. 本機 CLI 明確登記資料夾與父層；不依名稱猜測分類，不自動修改 NFO。
4. NFO resolver 取得資料庫擁有的資料夾位置，Series 只讀 `tvshow.nfo`，Season 只讀 `season.nfo`，大小寫比對及歧義拒絕沿用現有規則。
5. Reader 核對根目錄、資料夾及 NFO 的實體身分；重新檢查可辨識資料夾替換。不得把資料夾當普通影片開啟。
6. Season 保存季編號、文字及已支援的共用欄位，保留來源、人工清除與獨立鎖；既有投影語彙保持。
