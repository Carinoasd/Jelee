# 使用者視圖移除直播與頻道相依

依 G05，使用者視圖管理器移除直播／Channel管理器的建構相依與欄位，刪除外部直播／頻道資料夾增補及Channel最新項目的外部抓取分支。一般資料夾分組、排序、隱藏與本機最新項目查詢保留。既存Channel父項現在走一般本機媒體庫查詢；尚未刪除其存量資料，不把這段當成資料清理完成。

新舊HTTP視圖路由與舊external query flag保持可接受，flag不再增補退休功能，OpenAPI參數註解同步。四項單元驗收覆蓋本機資料夾在true／false下保留，以及普通／既存Channel父項使用一般最新項目查詢；正式登入HTTP新舊路由各驗證false／true／預設，共兩項測試六次請求全通過。HTTP測試主機沒有預先建立退休調諧器或媒體庫，不能當成全部舊資料遷移證據。
