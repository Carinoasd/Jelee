# 原生忽略規則目錄列舉

`ignoresource.Resolver.ScanDirectory` 以可信的已登記根路徑、根相對目錄與大小寫選項執行列舉。它先讀取可達祖先規則，再從提供目錄身份證明的同一個句柄列舉直接子項。每個目錄建立一次規則程式，逐項回傳包含命中來源的判定，不為每個檔案重新開啟整條祖先鏈。

每批最多128項，附上獨立擁有的根到當前目錄證明。資料批次均為暫存觀察；重新開啟並核對所有祖先身份、規則存在狀態及完整內容摘要，且所有句柄成功關閉後，才回傳空的 Done 批次及跳過數。工作程序仍須把這些證明與持久清單比對，最後再執行全掃描復核及 seal。

## 原生句柄與缺失

- Linux 以既有嚴格 openat2 開啟目錄。列舉使用同句柄的 Readdirnames，每個子項以 fstatat 和 AT_SYMLINK_NOFOLLOW 取得屬性；不依賴被隱藏的檔案名稱重新查詢路徑。
- Windows 以既有 NtCreateFile 句柄列舉；Go 1.27.1 的 ReadDir 保存該目錄查詢所回傳的屬性，DirEntry.Info 直接回傳這些屬性，不另開路徑。
- 連結、FIFO、裝置及其他不允許的類型計入跳過，不開啟內容。被規則排除的目錄不會為了讀其規則而進入。
- 私有 OpenDirectoryOrAbsent 只對已開啟父句柄的單一合法子名稱操作。真正的子名稱不存在才回傳 absence；父句柄失效、權限錯誤、非目錄或連結不能轉成不存在。

## 取消與限制

沿用來源處理的兩個並行名額、30秒共用期限、路徑/深度/來源大小和累積編譯上限。取消會關閉正在列舉的句柄；回呼失敗會保留原錯誤並停止，沒有 Done。沒有假設原生開啟或 stat 可被硬性中止，也不聲稱提供檔案系統原子快照。

公開掃描批次與條目會隱藏 JSON 欄位及日誌格式化內容。批次沒有絕對路徑、規則原文或可共享檔案句柄。回呼持有自己的證明副本，修改它不影響後續復核。

## 狀態與驗證

已驗證 Windows 來源套件、架構測試和 vet，以及原生 Linux /tmp 快照下的來源套件 race 與 vet。Linux 零跳過、來源套件覆蓋率87.2%；包括有界分頁、規則與目錄替換、取消、回呼錯誤、排除祖先不進入、符號連結與FIFO。Windows 根替換測試直接替換正在列舉的根，避免作業系統對開啟子目錄時移動祖先的限制。

尚未接上持久掃描批次、舊基準缺失祖先的公開觀察、全清單重新觀察或 worker/API/CLI；enabled 任務仍不會被領取。詳細来源 SHA 與指令見[驗證證據](evidence/ignore-native-scan.json)。
