# G05 直播核心註冊解耦

移除直播、指南、預設直播服務與專用 DTO 的四個服務註冊，以及一般主機的延遲直播註冊。程序集探索改以仍被媒體庫使用的錄製管理器作標記，保留原程序集中的必要元件。

六項整合驗收同時檢查服務集合與實際啟動主機：五個退休服務無法解析，頻道、錄製、節目來源與調諧器管理器仍能正常解析。程序集內容與七個核心實作／介面本階段均保留，待接續移除；這不是完整直播裁剪驗收。

本階段只改三份註冊／程序集來源，沒有修改原媒體、既有遷移或授權資訊。存量資料、調諧器、頻道與錄製實體及其媒體庫相依仍待處理。完整方案與門禁結果見[證據](evidence/live-core-registration-removal.json)。
