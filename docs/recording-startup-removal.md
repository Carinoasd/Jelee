# 移除錄製自動啟動來源

依 G05 刪除錄製啟動 host 與通知 host，連同正式 Startup 註冊；移除錄製管理器訂閱設定更新的回呼。伺服器啟動不再透過這個 host 恢復既存計時器或建立錄製目錄，設定更新也不再透過這個回呼建立錄製媒體庫。既存計時器資料保留，未改已發布遷移、原始媒體或授權文件。

三項回歸覆蓋正式 host 註冊、編譯程序集的已刪類型，以及設定事件不得再訂閱、查設定或操作媒體庫。正式依賴仍可解析。三項通過；暫用此前四個正式來源時三項全部失敗，最後逐位元恢復來源（包含兩個檔案保持已刪除），再跑完整 Debug 回歸：17 套件、4,159 Passed、21 NotExecuted、零失敗。格式檢查通過，有工作區載入警告。

G05 保持部分完成：舊控制器、明確呼叫的錄製操作、EPG／Channel 排程及調諧器仍存在，不能把本段當成所有錄製入口已關閉。下一步移除相關 HTTP 控制器並回傳明確不支援，再清理排程與核心相依。ABI 檢查保留公開型別刪除的實際差異，完整品牌門禁仍未通過。
