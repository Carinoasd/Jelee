# NFO 合集結構

第35版新增 `collection-structure-v1`，在原有24欄後加入 `collection`；舊投影的欄位集合保持。

合集以 `facts[].field = collection` 的 JSON 物件保存：

| 屬性 | 契約 |
| --- | --- |
| name | 必填且不能只有空白；最多1024個 UTF-8 位元組 |
| overview | 可省略，省略代表空簡介；最多16384個 UTF-8 位元組 |

拒絕未知屬性、NUL、非法型別及屬性 null。人工整筆 `value: null` 表示明確清除；省略 value 保持原值。空物件與空陣列不是有效合集。

唯讀來源支援文本 `set`／`collection` 和結構 `set/name`／`set/overview`。名稱與簡介一起保存並共用來源證明和鎖。指定 `Set`／`Collection` 鎖時，即使缺值也保留獨立正鎖；人工清除優先於後續 NFO 確認。

正式套用必須拒絕重複合集別名、重複名稱與簡介，並保留原始 NFO。一般唯讀相容解析器不因此改寫檔案。來源觀察持有合集副本，重核名稱與簡介；查詢期間的變更不能混入確認結果。

新遷移保留第1至34版的68份已發布 SQL。保留合集資料（包括人工清除）、合集鎖或新版投影證明時拒絕降版。
