# 移除直播與頻道自動工作及提供者

依 G05 刪除 EPG／Channel 兩個排程、Channel 掃描後資料清理工作，以及直播／Channel 動態媒體來源與Channel圖片提供者。刪除五個排程觸發呼叫，兩個管理器不再注入排程管理器；調諧器保存介面與實作也移除只用於排程的旗標。這是實際刪除型別與相依，沒有空工作替代。

刪除僅由Channel排程使用的三個四語翻譯鍵，目前四份資源各121鍵，Windows／Linux資源門禁通過。未修改既存遷移、存量計時器、原始媒體與授權文件。

十項回歸檢查六個型別確實不在編譯程序集、正式host的排程清單與登入API都無退休工作，並確認兩個管理器不再相依於排程管理器。全部通過。暫恢復舊六個工作／提供者，八項相關驗收全部失敗；恢復刪除狀態後完整Debug17套件4,808 Passed／21 NotExecuted／零失敗，格式檢查通過（工作區載入警告）。API讀取使用既有的JSON選項，保留原本PascalCase欄位與字串列舉協定。

G05仍部分完成：核心直播／EPG／調諧器／錄製／Channel管理器、實體及媒體庫相依仍存在，設定與存量資料、其他翻譯及圖示仍待清理；未宣稱真客戶端／LAN驗收完成。公開介面改動形成實際ABI差異，保持門禁。
